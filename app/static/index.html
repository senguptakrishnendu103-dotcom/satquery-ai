Remote Sensing Adaptation Datasets

Supported Fine-Tuning & Evaluation Benchmarks

SatQuery AI's architecture features modular interfaces designed for zero-shot and fine-tuned remote-sensing vision-language models. Models can be integrated across standard benchmarks:

  • BigEarthNet-MM: Multi-modal Sentinel-1 & Sentinel-2 land cover classification dataset (590,326 image patch pairs).
  • RSVQA: Remote Sensing Visual Question Answering benchmark for low-resolution and high-resolution optical imagery.
  • VRSBench: Comprehensive benchmark for visual reasoning, captioning, and grounded VQA in satellite imagery.
  • CDVQA: Change Detection Visual Question Answering benchmark for bi-temporal remote sensing pairs.
Clean Python BaseRSModel abstract class enables seamless hot-swapping of PyTorch / ONNX model weights without modifying UI components.

Product Principles

SatQuery AI is an AI Agent platform for understanding and analyzing remote-sensing imagery. It is NOT simply a generic image chatbot or satellite viewer.

The system dynamically determines required remote sensing analysis (VQA, Grounding, Bi-Temporal Change Detection, Optical-SAR Fusion), executes specialized models, overlays visual spatial evidence, and provides auditable execution summaries.
